## The three highest-priority defects found

1. **D01 - Reports page crash on list click (high, fixed).** A user clicking any saved report in the list while none was selected got a blank page. Fixed in `Reports.jsx`; browser regression test UI-E-010b.
2. **D02 - Unguarded concurrent GPU evaluations (high, fixed).** The Models page "Evaluate" button could start several evaluations at once on the 4 GB GPU; all four failed and the user saw nothing. Now 409 + visible confirmation.
3. **D07 / D05 - Integrity gaps in what the system trusts (medium, fixed).** A checkpoint whose bytes did not match its sidecar hash was accepted as a verified dental model, and the report validator accepted impossible evidence (probability 1.7, a label no model can produce).

Highest-priority **open** items: no authentication or rate limiting (acceptable only on loopback), unreviewed Hindi/Marathi wording, and the fact that the original active-learning conclusion (no benefit over random) is smaller than the run-to-run/device noise measured here (D22).

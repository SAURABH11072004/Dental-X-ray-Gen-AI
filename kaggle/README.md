# Kaggle GPU run: finding-classifier imbalance experiments

Everything heavy (2.9 GB image download, 35 to 40 ResNet-50 runs) happens on Kaggle. Locally you only build a small bundle and,
afterwards, verify and stage the downloaded checkpoints. **No step changes the production model, its checkpoints or thresholds.**

| File | Purpose |
|---|---|
| `denta_mind_training.ipynb` | the notebook (generated by `make_notebook.py`; edit that file, then regenerate) |
| `dentamind_kaggle.py` | data loading, crops, weights, sampler, focal loss, resumable training, evaluation, acceptance rule |
| `build_kaggle_bundle.py` | packs code + manifests + detector-box cache (+ deployed model for reference) into `dist/dentamind_kaggle_bundle.zip` |
| `stage_kaggle_candidates.py` | verifies the downloaded archive and stages checkpoints in `checkpoints/kaggle_candidates/` |

## 1. Build the bundle (local, a few seconds)

```powershell
.venv\Scripts\python.exe scripts\dataset\audit_class_imbalance.py      # only if data changed
.venv\Scripts\python.exe scripts\dataset\build_combined_manifest.py    # only if data changed
.venv\Scripts\python.exe kaggle\build_kaggle_bundle.py --with-deployed-checkpoint
```

This produces `kaggle\dist\dentamind_kaggle_bundle.zip` (about 84 MB). It contains no radiographs.

## 2. Upload it as a PRIVATE Kaggle dataset (needs your Kaggle account)

Web UI: kaggle.com -> **Datasets -> New Dataset** -> upload `dentamind_kaggle_bundle.zip` -> title `dentamind-bundle` ->
visibility **Private** -> Create. (Kaggle may unpack the zip; the notebook handles both forms.)

Or with the CLI: `pip install kaggle`, download an API token (kaggle.com -> Settings -> API -> Create New Token), save it as
`%USERPROFILE%\.kaggle\kaggle.json`, then:

```powershell
kaggle datasets init -p kaggle\dist          # edit kaggle\dist\dataset-metadata.json: title, id "<your-username>/dentamind-bundle"
kaggle datasets create -p kaggle\dist        # creates a private dataset by default
```

## 3. Create and run the notebook

1. kaggle.com -> **Code -> New Notebook -> File -> Import Notebook** -> choose `kaggle\denta_mind_training.ipynb`.
2. Right-hand panel -> **Session options**: Accelerator **GPU T4 x2** or **GPU P100**, **Internet On** (Internet requires a
   phone-verified account; it is needed to fetch DENTEX from Hugging Face).
3. **Add Input** -> Your Datasets -> `dentamind-bundle`.
4. Optional: lower `SEEDS` or trim `RUN` in the first cell for a quick trial. The full plan is 7 experiments x 5 seeds (+5 runs for
   E if justified). At about 4 min per run on a T4 this is about 2.5 to 3.5 h, inside one session.
5. Click **Save Version -> Save & Run All (Commit)**. It runs in the background (up to 12 h) and keeps `/kaggle/working`
   as the version's output.

If the session ends early, every finished run is kept. Add the previous version's output as an input, set
`RESUME_FROM = "/kaggle/input/<that-output>/dentamind_artifacts/runs"` in the first cell, and commit again. Finished runs are
skipped, and an interrupted run continues from its last completed epoch.

## 4. Download the result

Notebook page -> **Output** -> `dentamind_balanced_training_artifacts.zip`, or `kaggle kernels output <user>/<notebook-slug> -p .`

## 5. Verify and stage locally (never activates anything)

```powershell
.venv\Scripts\python.exe kaggle\stage_kaggle_candidates.py C:\path\to\dentamind_balanced_training_artifacts.zip
```

This checks every member against `SHA256SUMS.txt` and each checkpoint against its sidecar. It extracts to
`checkpoints\kaggle_candidates\<archive-sha8>\` (outside `data\checkpoints`, so the model registry never sees it), loads each model
with the production construction (`strict=True`), re-runs it on the cached validation crops, compares macro-F1 with the Kaggle value,
and confirms with a hash snapshot that no production file changed. The summary goes to `reports\checkpoint_manifest.json`.

Promotion is a separate, explicit decision that goes through the project's promotion workflow.

## What the notebook guarantees

* Images are fetched only from the official DENTEX release and must match the manifest SHA-256 byte for byte, or the run stops.
* Validation = the project's fixed validation split; the test split is read only for BASE and for candidates that pass.
* Class weights and sampler probabilities are computed from training rows only.
* Acceptance = the project's pre-registered criteria (`data/reports/training_recipe_comparison_protocol.md` section 5 plus the minority
  precision condition of the earlier imbalance study), applied unchanged with BASE as the baseline.

# External-data experiment (`denta_mind_external_training.ipynb`)

Protocol: `reports/external_data_protocol.md`. Runs BASE, X1_cluj, X2_hanoi and X3_both, 5 seeds each (20 runs, about 3–4 h on a T4).

1. Build the Hanoi crops locally once: `.venv\Scripts\python.exe scripts\dataset\external_crops.py hanoi` (about 1 h on the RTX 3050).
2. Build the bundle: `.venv\Scripts\python.exe kaggle\build_kaggle_bundle.py --with-deployed-checkpoint --with-external`.
3. Upload `kaggle\dist\dentamind_kaggle_bundle.zip` as a **new version** of your private dataset `dentamind-bundle`.
4. Import `kaggle\denta_mind_external_training.ipynb`, set GPU T4/P100 and **Internet On** (it downloads DENTEX from Hugging Face
   and Cluj from Zenodo), add the dataset, then **Save & Run All (Commit)**.
5. Download `dentamind_external_data_artifacts.zip` from the Output tab and stage it with `kaggle\stage_kaggle_candidates.py` as before.
